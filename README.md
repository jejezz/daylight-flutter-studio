## Features

- **Project tree + light editor** — syntax highlighting, Dart bracket folding, Dart formatting (Ctrl+Alt+L), Markdown preview, change bars against HEAD, `dart analyze` problems
- **Run panel** — pick a device and Debug/Release, build and install; a successful run records a verification for that commit
- **Git panel with a merge gate** — status, fetch/pull/push, create and merge PRs; only verified commits merge by default
- **Light & dark, English & 한국어** — follows the system, or pick one in the toolbar

## Install

Download from [**Releases**](https://github.com/jejezz/daylight-workbench/releases/latest):

| OS | File |
|---|---|
| macOS 12.0+ | `DaylightWorkbench-<version>-macos-universal.dmg` — open it and drag Daylight Workbench to Applications |
| Windows 10/11 (x64) | `DaylightWorkbench-<version>-windows-x64-setup.exe` |

**Windows:** the installer isn't code-signed yet, so SmartScreen says "Windows protected your PC" — choose **More info → Run anyway**.

## How it works

The Run and Git panels reuse the code of Flutty Dock and Branch Dock. A verification record (`<git-common-dir>/dock-verify/<sha>.json`) ties a successful device build to a commit, and the merge gate checks that record before a PR is merged.

## Development

```bash
flutter pub get
flutter run -d macos
```

Needs the Flutter SDK, `git` and the GitHub CLI (`gh`) on your PATH. Plans and current status: [PLAN.md](PLAN.md).

Releasing: `scripts/bump-version.sh patch`, merge, then tag `vX.Y.Z` — CI builds and publishes every platform. Rules: [application-release-templates/conventions](https://github.com/jejezz/application-release-templates/tree/main/conventions).
